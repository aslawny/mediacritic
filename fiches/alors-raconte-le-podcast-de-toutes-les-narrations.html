À propos de ALORS RACONTE, le podcast de toutes les narrations.

Je suis Anne-Elisabeth Le Gal, scénariste et réalisatrice. Dans ce podcast, je vous emmène dans les coulisses de l’écriture : la création audiovisuelle bien sûr mais aussi les romans, les chansons, les publicités, les formats web, la mise en scène, le théâtre, les expo, en un mot — toutes les histoires qui nous racontent des histoires.
